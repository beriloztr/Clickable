# Clickable
A fast-paced, web-based reaction game where speed and precision are key. Click the active cells before the timer runs out to achieve the highest score!

Built With:
- HTML5: Semantic structure.
- CSS3: Custom animations and flexbox layout.
- Vanilla JavaScript: Game logic, DOM manipulation, and interval management.

*Features*
- Dynamic Scoring: Points are calculated based on your reaction speed.
- Progressive Difficulty: Multiple cells appear to keep the intensity high.
- Persistent High Score: Uses localStorage to keep track of your personal best across sessions.
- Visual Feedback: Features smooth CSS animations and a "Confetti" celebration for new high scores.
- Responsive UI: Clean, "Bubblegum Sans" styled interface with a mobile-friendly layout.
*Game Play*
- The Countdown: When you start, a 3-second countdown will prepare you for the challenge.
- Click the Black Cells: Once the game starts, black cells will appear randomly on the grid.
- Speed Matters: A blue progress bar at the top indicates your bonus multiplier. The faster you click, the more points you earn!
- Beat the Clock: You have a limited time to score as many points as possible.
- High Scores: Your best performance is saved locally on your browser. Can you beat your own record?

To Play:
- Clone this repository or download the source files.
- Ensure game.html, layout.css, and gamescript.js are in the same folder.
- Open game.html in any modern web browser.
